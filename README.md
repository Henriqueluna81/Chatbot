# Agente Inteligente de IA no WhatsAPP

Neste projeto usamos foi usada IA da Meta, a **Llama** para ser inserida no contexto de agente em nosso projeto. Esse sistema foi feito com o foco em melhorar o atendimento aos clientes de uma empresa de telecomunicação. O foco dele inicial é prestar suporte para todos os usuários em tempo real, para tranquilizar e informar todos os usuários. 

Neste projeto usamos tecnologias simples em LangChain, pois não se trata de um projeto que precise de uma treinamento tão especifico da IA, então apenas delimitações de contextos atendião as necessidades do cliente e foi isso que o nosso projeto trouxe. Simplicidade e velocidade de resposta.


## Ferramentas utilisadas 

Nesse projeto usamos bibliotecas conhecidas e APIs conhecidas para o desenvolvimento simples desse projeto e de fácil continuidade caso a empresa precise desenvolver outras coisas por cima dessa aplicação. Então fizemos o uso do **Phython** como linguagem base do projeto, **Whara** como API de WhatsApp para conexão do sistema com o app de mensagem, **LangChain** para manipulação da IA dentro do sistema, **Flask** como framework do projeto e por fim, usamos como IA o **Llama**, IA da Open-Source da Meta, pegamos a versão criada pela **Groq**, que disponibiliza uma gratuitamente essa IA para uso.  

| Ferramentas | Finalidade de cada tecnologia |
|--|--|
| Llama | O chama Usamos uma imagem treinada dele criada pela Groq, onde a IA já possui um treinamento previo, com milhões de parametros, que torna o uso dela bem simples em projetos. |
| Whara | O Whara é um sistema de código aberto que tem a funcionalidade de simular um WhatsApp Web para facilitar a comunicação do de um sistema criado com a plataforma do WhatsApp. Então usamos a versão gratuita desse sistema para integrar no projeto.|
|Python |O Python é uma foi usado no projeto por já ser uma linguagem que tem uma melhor adaptabilidade com sistemas que interagem diretamente com dados e IA. Então pensando em um desenvolvimento sem muitos problemas, de fácil compreensão, foi usado o Python nesse projeto. |
| Flask | O Flask é um **FrameWork** Python bem leve é de fácil manipulação. Por não possuir muitas complexidades, o Flask foi escolhido como o FrameWork desse projeto. |
| LangChain | O LangChain é um **frameWork** com feito para trabalhar com grandes modelos de IA (LLM), por isso usamos ele no projeto, para que a inserção da IA seja fácil e bem administrada. |
| Docker | O Docker foi usado nesse projeto para encapsular esse projeto e torna-lo fácil de ser manipulado por outras máquinas, tanto em linux quanto Windows. Então por sem bem completo e útil principalmente na parte de envio de imagem para outras máquinas, o Docker foi usado nesse projeto. |
